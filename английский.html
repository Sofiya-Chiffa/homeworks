📘 Essential English for IT Students

Развёрнутые ответы на экзаменационные вопросы (Parts 1 & 2)

1. How many generations of computers are there? What is the difference between them? Talk about each generation in detail.

There are five generations of computers.

  • First Generation (1940s): Used vacuum tubes. Enormous, expensive, consumed lots of electricity, generated excessive heat, solved one problem at a time (e.g., ENIAC).
  • Second Generation (late 1950s–1960s): Used transistors. Ten times faster, smaller, more reliable, less maintenance.
  • Third Generation (1965–1972): Used integrated circuits (ICs). Could perform a million calculations per second (1000× faster than first generation), even smaller.
  • Fourth Generation (mid–late 1970s): Used microprocessors. Supported GUI, mouse, networking, led to emergence of the Internet.
  • Fifth Generation (now developing): Based on parallel processing and Artificial Intelligence (AI). Aim to simulate human thinking, respond to natural language, learn and self-organize.
2. Talk about the contribution of Charles Babbage and John von Neumann.

Charles Babbage: Designed the Analytical Engine in the 1830s, which contained an ALU, control unit, memory, and I/O system — the essential parts of a modern computer. Often called the "father of the computer".

John von Neumann: In 1947 developed the idea of storing instructions inside the computer's memory (stored-program concept), which became the basis for modern computer architecture.

3. What do you know about Moore's Law?

In 1965, Gordon Moore predicted that computer processing power (the number of transistors on a chip) would double approximately every two years. The trend closely follows this prediction, leading to decreased transistor costs and increased computing power. Some analysts predict the growth will slow down and stabilize in the future.

4. Differences between mainframe, supercomputer, desktop PC, laptop, tablet, smartphone.
  • Desktop PC: Stationary, modular, customizable components (monitor, CPU, keyboard).
  • Laptop: Portable, battery pack, touchpad, similar performance to desktop.
  • Tablet: Mobile device with touchscreen, lacks physical keyboard, uses virtual keyboard or Bluetooth accessories.
  • Mainframe: Supports multiple users simultaneously, processes thousands of queries at once — used in banks/universities.
  • Supercomputer: Extremely high performance (billions of computations/sec), solves one complex problem at a time (weather forecasting, quantum mechanics).
  • Smartphone: Similar to tablet but smaller (<7 inches), supports cellular network.
5. Talk about the CPU (three main parts, factors affecting performance).

Three main parts: Control unit (interprets instructions), ALU (arithmetic/logic operations), Registers (high-speed memory for data/control).

Performance factors: Clock speed (measured in GHz – higher is faster) and number of cores (multi-core CPUs enable better multitasking).

6. What is cache memory? Write‑through, write‑back, cache hit?

Cache memory: Very fast memory on the CPU acting as a buffer between RAM and processor, storing recently accessed data.

Write‑through cache: Updates cache and main memory simultaneously — safer but slower.

Write‑back cache: Updates cache first; main memory updated only when cache block is replaced — faster but requires more advanced controller.

Cache hit: When the processor finds the required data in the cache, avoiding a slower access to main memory.

7. What is ROM? What is stored in ROM? Types of ROM.

ROM (Read Only Memory): Non‑volatile memory that retains data when power is off. It stores the BIOS instructions to start the computer.

Types: MROM (masked, outdated), PROM (one‑time programmable), EPROM (erased by UV light), EEPROM (electrically erasable, byte by byte), Flash ROM (modern, faster, high endurance).

8. What is RAM? What data is stored? Two types of RAM.

RAM (Random Access Memory): Volatile "working memory" that stores data temporarily while the computer is running. A copy of active data is transferred from secondary storage to RAM.

Two main types: DRAM (needs constant refresh, slower, cheaper) and SRAM (does not need constant refresh, faster, more expensive – used for cache).

9. Differences between primary memory and secondary storage devices. Examples.

Primary memory: Internal, directly accessed by CPU, minimal delay, can be volatile (RAM, cache) or non‑volatile (ROM). Examples: RAM, ROM, cache.

Secondary storage: Long‑term retention, always non‑volatile, NOT directly accessed by CPU, slower but much larger capacity. Examples: HDD, SSD, USB flash drives, optical discs.

10. How can secondary storage be classified? Talk about each category.
  • Magnetic storage: Stores data by magnetizing particles — HDDs, floppy disks, magnetic tapes.
  • Optical storage: Uses laser beams to read/write reflective marks — CDs, DVDs, Blu‑ray discs.
  • Flash memory (solid‑state): Non‑volatile, electronically erased/reprogrammed, no moving parts — USB drives, SSDs, memory cards.
11. Talk about HDD. Construction, recording process, fragmentation/defragmentation.

Construction: Magnetic platters, read/write heads, tracks and sectors.

Recording: Data is converted to binary; magnetized area = 1, demagnetized = 0. The read/write head changes magnetization.

Fragmentation: When files are split into pieces scattered across the disk.

Defragmentation: Reassembles related pieces into contiguous physical locations, improving speed.

12. Types of optical storage devices.
  • CD: 700 MB, available as CD‑ROM, CD‑R (recordable once), CD‑RW (rewritable).
  • DVD: 4.7–8.5 GB, tracks closer together, smaller pits.
  • Blu‑ray: Uses blue laser, up to 128 GB, high‑definition video.
13. Two types of flash memory. Differences in functionality and use cases.

NOR flash: Direct random access, ideal for code execution, bootloaders, firmware, microcontrollers (automotive, medical devices).

NAND flash: High‑density storage, used in SSDs, USB drives, mass storage devices. Slower for random small data access.

14. What is software? Difference between system and application software. Types of system software.

Software: A set of instructions/programs that operate a computer system.

System software: Runs in background, manages hardware resources, provides platform for applications. Types: OS, firmware, device drivers, assemblers, utilities.

Application software: Runs in foreground, helps user perform specific tasks (word processors, browsers, databases). Cannot run without system software.

15. What is an OS? Main functions. Main types with examples.

OS (Operating System): Acts as intermediary between application programs and hardware. Functions: managing hardware resources, user interface, environment for applications.

Types: Desktop (Windows, macOS, Linux), Mobile (Android, iOS), Single‑tasking (MS‑DOS), Multi‑tasking (Windows, Linux), Single‑user, Multi‑user (Unix), CLI (Unix), GUI (Windows, macOS).

16. Two types of multitasking (preemptive and cooperative). Differences.

Preemptive multitasking: OS allocates a time slice to each process; decides when to switch, based on priority.

Cooperative multitasking: Processes voluntarily yield control to others; all must cooperate.

Difference: Preemptive uses OS‑controlled scheduling; cooperative relies on processes to give up CPU time willingly.

17. Criteria for network classification. Provide several classifications.
  • Geographical area: LAN, MAN, WAN.
  • Architecture: Client‑server, Peer‑to‑peer.
  • Topology: Bus, Star, Ring, Mesh, Tree, Hybrid.
  • Connectivity type: Wired (coaxial, fiber) and Wireless (Wi‑Fi, Bluetooth, satellite).
18. Network topology. Describe different topologies with benefits and downsides.
  • Bus: Single cable – easy to extend, but backbone failure brings down network.
  • Star: Central hub – one node failure doesn't affect others; central hub failure breaks everything.
  • Ring: Each node connected to two others – easy setup, but one shutdown stops whole network.
  • Mesh: Fully connected – high reliability, expensive, redundancy.
  • Tree: Combines bus and star – flexible, scalable.
19. Main hardware components of a network and their functions.
  • Modem: Modulates/demodulates signals between ISP and local devices.
  • Router: Connects networks, forwards packets, allows multiple devices to share connection.
  • Hub: Broadcasts data to all devices (Layer 1).
  • Switch: Inspects packets, routes based on MAC addresses (Layer 2).
  • Bridge: Divides network into segments, improves performance.
  • Gateway: Connects dissimilar networks via protocol translation.
20. Talk about the OSI model. Name layers, their functions and protocols.
  • Physical (1): Raw bits over medium.
  • Data Link (2): Frames, MAC addresses, error control.
  • Network (3): Routing, IP addresses, packets.
  • Transport (4): Segments, error checking (TCP, UDP).
  • Session (5): Manages sessions, checkpoints.
  • Presentation (6): Encryption, compression, translation.
  • Application (7): User‑facing protocols (HTTP, FTP, SMTP).
21. Types of wired internet connection. Talk about each.

Coaxial / twisted‑pair: Used for LAN connections over shorter distances.

Fiber‑optic cables: High‑speed, long distances, uses light pulses, low attenuation, very high bandwidth.

22. Three types of DSL connection. Difference between DSL and dial‑up.

DSL types: ADSL (asymmetric, download faster than upload), SDSL (symmetric), VDSL (very high bit‑rate).

DSL vs dial‑up: DSL uses higher frequency bands, simultaneous voice/data, dedicated line, no sharing. Dial‑up uses same frequency for voice/data, cannot use phone and Internet at the same time, slower.

23. Three wireless internet access technologies. Benefits, downsides, equipment.

Wi‑Fi: Medium range, uses router/access point; benefits: mobility, downsides: signal interference, less secure.

Cellular (4G/5G): Wide area, uses cell towers; benefits: coverage, downsides: data caps, signal variability.

Satellite: Long distance, uses dish and modem; benefits: remote areas, downsides: latency, weather sensitivity.

24. Difference between the Internet and the WWW.

Internet: Global network infrastructure (hardware, protocols). WWW: An information system accessible via the Internet, using browsers, HTML, URLs. The Web was invented by Tim Berners‑Lee in 1989; it is not synonymous with the Internet.

25. Packet switching and circuit switching technologies.

Circuit switching: Dedicated path for the whole communication (telephone networks). Wastes bandwidth when idle.

Packet switching: Data broken into packets, each takes its own route, reassembled at destination (Internet). Efficient bandwidth use.

26. Three types of search engines. Three steps of crawler‑based search engines.

Types: Crawler‑based (Google), human‑powered directories (Yahoo Directory), meta‑search engines (Dogpile).

Steps: Crawling (spider finds content) → Indexing (store and assign keywords) → Ranking (order by relevance).

27. Classification of programming languages. Compiler, interpreter, assembler.

Low‑level: Machine code (binary), assembly (mnemonics) – hardware‑specific.

High‑level: Closer to human language, portable (C, Java, Python).

Assembler: Translates assembly into machine code. Compiler: Converts whole high‑level code to machine code in one go. Interpreter: Executes line by line at runtime (slower, more memory).

28. What is OOP? Three key features of OOP.

OOP bundles data and methods into objects. Encapsulation: Hides internal state, bundles data with code. Inheritance: Child classes inherit properties from parent. Polymorphism: Same interface, different implementations.

29. Three main tools in web design. Website builders advantages/disadvantages.

HTML – structure; CSS – styling; JavaScript – interactivity.

Website builders pros: No coding, templates, WYSIWYG, drag‑and‑drop, affordable. Cons: Limited customization, less scalable, may have commercial restrictions.

30. Frontend vs backend development. SEO. On‑page vs off‑page SEO.

Frontend: UI, HTML/CSS/JS, user interaction. Backend: Server side, databases, logic (Python, Java, PHP).

SEO: Set of improvements to rank higher in search results. On‑page: Content, keywords, HTML tags. Off‑page: Backlinks, social signals, external factors.

31. What is malware? Damaging effect of ransomware, spyware, adware, Trojan, miner.
  • Ransomware: Encrypts data, demands payment for decryption.
  • Spyware: Secretly gathers personal information.
  • Adware: Displays unwanted ads; annoying, may track behavior.
  • Trojan: Disguised as legitimate, creates backdoors, steals data.
  • Miner (cryptojacker): Uses victim's CPU/GPU to mine cryptocurrency, slowing system.
32. Four routines of a virus. Difference between virus and worm.

Routines: Misdirection (hide), reproduction (copy itself), trigger (activate payload), payload (damage).

Virus: Needs host program to spread. Worm: Self‑replicating, spreads independently without host.

33. What is cybercrime? Damaging effect of phishing, website defacement, piggybacking, salami shaving.
  • Phishing: Steals credentials via fake messages → identity theft, financial loss.
  • Defacement: Vandalising website → reputation loss, business disruption.
  • Piggybacking: Unauthorised wireless access → data breach.
  • Salami shaving: Small thefts from many accounts → large cumulative fraud, hard to detect.
34. Difference between DoS and DDoS attack. How is DDoS performed?

DoS: Single source floods target. Easier to block. DDoS: Multiple compromised devices (botnet) overwhelm target. Harder to stop.

Performed: Attacker builds botnet (infected machines), then commands them to send massive traffic to victim simultaneously.

35. What is a firewall? What can firewall filters be based on?

A firewall protects private networks by filtering incoming/outgoing traffic. Filters can be based on IP addresses, domain names, port numbers, packet content, or specific keywords.

36. How does antivirus work? Signature‑based vs heuristic scanning. What is a signature?

Signature: Unique fingerprint of known malware.

Signature‑based: Matches files against known signatures — only detects known threats.

Heuristic scanning: Uses rules and algorithms to detect new, unknown malware by analyzing behaviour/commands.

37. What is encryption? Difference between two main types. Two methods of breaking a cipher.

Encryption: Converts plaintext to ciphertext to protect data.

Symmetric: Same key for encryption/decryption. Asymmetric (public key): Public key encrypts, private key decrypts.

Breaking methods: Brute force (try all keys) and cryptanalysis (exploit cipher weakness).

38. Talk about artificial neural networks. Structure, tasks, classification vs clustering.

ANN: Simulates biological neurons with interconnected nodes (input, hidden, output layers). Uses weighted connections.

Tasks: Face recognition, fraud detection, machine translation, autonomous driving.

Classification: Assigns data to predefined classes. Clustering: Groups data into undefined categories based on patterns.

39. What is backpropagation? Why are neural networks compared to 'black boxes'?

Backpropagation: Learning algorithm that adjusts weights by propagating error backward from output to input. Reduces difference between actual and expected output.

Black boxes: You feed data and get answers, but cannot easily explain internal decision‑making process. Lacks transparency.

40. What is IoT? Where can it be implemented? Major problems in using IoT.

IoT (Internet of Things): Network of physical objects with unique identifiers that transfer data without human intervention.

Implementation: Smart homes, wearables, agriculture, automotive, logistics, healthcare.

Major problems: Security risks, massive device management, lack of standardisation, potential system‑wide bugs, privacy concerns.
